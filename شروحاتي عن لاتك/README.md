# كتابة النص العربي في LaTeX

## المحركات الأساسية والحلول المتاحة

تقرير تقني شامل من إعداد **الدسوقي المتولي الخولي**، يشرح كتابة النص العربي وتنسيقه في نظام `LaTeX` مع مراعاة اليونيكود، والخطوط العربية، وتشكيل الحروف، والاتجاه ثنائي المسار بين العربية واللغات اللاتينية.

## موضوعات الكتاب

- المتطلبات التقنية للكتابة العربية: الترميز، المحرك، تشكيل الخط، الاتجاه، والحزمة اللغوية.
- المقارنة العملية بين `pdfLaTeX` و`XeLaTeX` و`LuaLaTeX` و`ConTeXt`.
- حلول العربية التقليدية، ومنها `ArabTeX` و`arabi` و`babel`.
- الحلول الحديثة المبنية على اليونيكود وخطوط `OpenType`، ومنها `fontspec` و`polyglossia` و`bidi` و`arabxetex` و`arabluatex`.
- أمثلة برمجية قابلة للتشغيل وجداول مرجعية للأوامر الشائعة.
- توصيات لاختيار المحرك والحزمة المناسبة للمقالات والكتب والعروض والنصوص المحققة.
- معالجة الأخطاء الشائعة في الخطوط، واتجاه النص، والنسخ من ملف `PDF`، وظهور العربية داخل الشفرة البرمجية.

## بنية الوثيقة

1. مقدمة وشرح طبقات دعم العربية.
2. فصول مستقلة للمحركات الرئيسية.
3. مقارنة المزايا والقيود والتوصيات العملية.
4. نصائح لحل المشكلات الشائعة.
5. ملاحق مرجعية مرتبة تبدأ بمسار `pdfLaTeX`، ثم `ArabTeX` و`arabi`، ثم المحركات والحزم الحديثة.

## التجميع

الملف الرئيسي هو `arabic text in latex.tex`، وهو مُعدّ للتجميع باستخدام `XeLaTeX`:

```bash
xelatex "arabic text in latex.tex"
xelatex "arabic text in latex.tex"
```

التجميع مرتين يحدّث الفهرس والإحالات الداخلية. تتطلب الوثيقة وجود الخط المحلي داخل المجلد `fonts/`، كما تستخدم بعض الخطوط المثبتة في النظام مثل `Noto Naskh Arabic` و`TeX Gyre Termes` و`ALM Fixed`.

## خصائص الإخراج

- بيانات وصفية عربية مضمّنة في ملف `PDF`.
- روابط قابلة للنقر بألوان هادئة ومن دون إطارات حمراء.
- أرقام أسطر لاتينية داخل بيئات `lstlisting`.
- دعم منسق للنص العربي داخل أمثلة الشفرة، مع الحفاظ على عرض الشفرة نفسها من اليسار إلى اليمين.
